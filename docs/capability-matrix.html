2. 通过标准

判定很简单：训练之后模型效果变好了，再加上几条保证这次训练真实有效的检查。下面四条全过才算「可用」。

四条判据（① 能完整跑完、② 效果变好、③ 算法正确性检查、④ 能推理）全部通过 ⇒ 才能标「已验证可用」；任一条不过 ⇒ 不得标「已验证可用」（按事实标「已验证不可用 / 尚未验证 / 未纳入验收」）。

  1. 能完整跑完：训练正常结束、不中断、不报错：退出码 0、优化器步数达标、检查点完整、没有 NaN/Inf；算法机制真的在起作用（不是空转）；产物能加载或推理。
  2. 效果变好（核心判据）：在平台方数据集与平台方参数下，训练之后模型效果比不训练好（逐算法通过线见下）：
    • SFT（监督微调）：训练后工具调用准确率提升至少 10.0 个百分点，判据 after − base ≥ +10.0 pp
    • GRASPO（强化）：训练后工具调用准确率提升至少 5.0 个百分点，判据 after − base ≥ +5.0 pp
    • CPT（继续预训练）：训练 loss 正常下降、准确率不下降，判据 after ≥ base（不劣化）
    • OPD（蒸馏）：学生准确率不下降，判据 学生 after ≥ base（能力回收）
  3. 算法正确性检查通过：SFT / GRASPO / CPT / OPD 各按自己的检查清单逐项通过（这是第 1 条的组成部分）；GRASPO 的算法逻辑严禁改动。
  4. 能推理：合并 LoRA 后用 vLLM 启动，实际前向一次能拿到可解析输出。

判据标识 elam-v3-allright-1。已冻结（现行口径，2026-10-15）：判据② 逐算法分列；不放宽判据；判定一律用点估计 Δ —— 不做假设检验、不引入置信区间 / 显著性。

3. 实验条件

下列条件对全部档位成立（复现时照这份清单，再加上表内该档一行即可）。

  • 基础模型：9B / 27B 两档规模；OPD 另需一个 27B 教师模型。
  • 算法：SFT（监督微调）/ GRASPO（强化）/ CPT（继续预训练）/ OPD（蒸馏）。
  • 训练后端：native / ms-swift（两者配置面不同，字段不可互换）。
  • 卡数：本矩阵档位使用 1／2／4 张卡（多卡时按卡数配置并行度）。
  • 可训练参数：LoRA 或全参。
  • 学习率：SFT / GRASPO = 5.0e-06；CPT / OPD = 2.0e-05。
  • 训练轮次（epoch）：SFT 4；GRASPO 8；CPT 2；OPD 2。
  • 训练数据：平台方自有、不公开；每档子集条数见矩阵表「训练数据」列。
  • 评测口径：
    • 评测集：平台方自有 / 不公开（100 行档用该档自身训练文件，同为非公开数据）。100 行档的评测集就是它自己训练用的那份 100 行文件（拿训练数据自测，只说明训练生效，不代表它在新数据上的表现）；其余档用平台方自有 702 行评测集。
    • 样本量：100 行档 = 100（fit 口径）；其余档 = 702；数据版本锚点：两种口径 —— 100 行档 = 该档自身训练文件（100 行，sha256 594d41b0…）；其余档 = 平台方自有评测集（702 行，c202b1e1…）。
    • 评测方法：工具调用准确率（acc）；温度 0；随机种子 42；一律用点估计 Δ 判定，不做假设检验。
    • 判据标识 elam-v3-allright-1；达标阈值见第 2 节「通过标准」。
  • 实验场所 / 代码版本：平台方内部训练集群；graspo · feature/refactor-three-layer-architecture · 8d63c38。
