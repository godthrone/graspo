GRASPO 算法说明

本文是 GRASPO 算法定义的对照文本：按本文逐条核对，即可判断实现对不对。算法逻辑严禁改动。

1. 一句话总述

GRASPO 是面向多模态工具调用的组相对策略优化：一个提示采一组 rollout，逐字符标注结构，另路解析打分给出结构化奖励，标注用于算 token 级 advantage，最后做裁剪后的策略梯度更新。

2. 字符级标注

对每条 completion 逐字符打角色标记，标记长度恒等于字符数；标注只标角色、不打分。标注是 token 级 advantage 的唯一输入；奖励不走标注：它由独立的解析与打分链路直接读 completion 文本（或其解析结果）算出，两者互不引用。

标记含义标注边界
S结构字符与期望模板逐字符匹配的标签、标点与字段名
V值字符参数值或 JSON value，按字段名归并成值段
Tthink 内容think 标签之间的全部字符
W多余文本前导、尾随与夹缝文本，不影响训练
E首个不匹配点结构 / 类型 / 拼写错误处；E 之后全部标 D
D截断区E 之后的所有字符，不训练

边界规则：值错误不置 E（交由相似度打分）；结构不完整（即无闭合标签，或 JSON 去掉围栏后不可解析）时，「末尾非空白字符置 E」不在标注阶段做，它是 advantage 计算前的一步后处理，见第 5 节。字符标记经 offset_mapping 派生 token 标记；一个 token 覆盖多字符时按「E 优先，其次 V，再次 S，再次 T，再次 D，其余 W」逐级取第一个命中的角色合并——只要其中有一个字符是 E，整个 token 就记 E，错误因此传导到整个 token。

3. 结构化奖励

单条 completion 的 reward 由三项相加后除以满分得到，满分由同一组检查项现算：

  1. 结构标记项：每命中一个期望标记（JSON 围栏、think 标签、工具调用结构）计 10 分；格式对而内容错的样本也能拿到基础分。
  2. 内容项：payload 与目标按结构递归比较（数值容差 0.2），多目标取最佳匹配；动作类型全对按内容分 ×100 计入，非数值字段全对（数值叶子被剥离后再比较）才算完全正确、再加 100；动作类型有错只计动作匹配分 ×100。填充文本超过 100 字符时，内容项整段不计。
  3. 反冗余项：非结构化填充文本按长度指数衰减计入，每 100 字符减半，最多约 1 分。

归一化：reward = 三项之和 ÷ 满分（满分 = 标记数上限 ×10 + 210）。因此完全正确的样本可以略高于 1。

上式里的固定部分即「满分基数」，它随取样情形取三种值，读者不必自己折算：

情形满分基数构成
默认230内容项上限 210 + 开、闭两个 JSON 围栏标记
默认 + think250内容项上限 210 + 四个标记（JSON 围栏两个 + think 标签两个）
工具调用210内容项上限 210，不计标记数
工具调用 + think230内容项上限 210 + 开、闭两个 think 标签标记

4. group 决策

一个提示一次采 N 条 rollout（rollout_group_size=8），决策只看整组 reward 的分布：

顺序决策条件处理
①完美跳过组内中位数 ≥ 1不训练
②可训练·最优正确组内最大值 ≥ 1正常训练
③重试最优样本不可解析重采一组，上限 5 次（rollout_max_retries）；达上限即丢弃
④可训练·最优不完美最大值 > 中位数正常训练
⑤重试最大值 < 1 且未达重试上限重采一组，上限 5 次（rollout_max_retries）
⑥丢弃组内无方差，或内容分一致且不满不训练（无偏好信号）
⑦丢弃最大值 == 中位数不训练（无偏好信号）

判定自 ① 向下短路：命中即停，后续条件不再参与。因此「最优不可解析 ⇒ 重试」（③）先于「最大值 > 中位数 ⇒ 可训练」（④）。中位数一律取下中位数：组内 reward 升序排列后取偏小的一侧，偶数条时也不是两侧平均。

不可解析的组默认拒在训练边界之外（reject_unparseable_groups 默认开启）：不进训练、不污染梯度。

组完整性：同一提示的 N 条必须同批、同权重版本；按数据并行切片时要求 N 可被切片数整除，否则拒绝启动——决策输入永远是整组。

5. token 级 advantage

字符标记映射到 token 标记后，advantage 按 token 逐位分配：S 记 +1.0，E 记 −1.0，T / W / D 记 0（不训练），V 记「该字段相似度 − 该字段组内均值」。

归一化是字段级组内相对化：μ_f 取该字段在全组同名字段值段上的均值，adv(V) = 相似度 − μ_f；不再做整组再加权归一化。计数单位是值段而不是样本：一条 completion 里同一字段出现多个值段，每个值段各计一份、各自打分。因此组内该字段只出现一个值段时，μ_f 恰等于该段的相似度，adv(V) = 0。对齐到策略张量时，提示位与填充位恒为 0。

末尾 EOS（advantage 的前置后处理）：结构不完整（无闭合标签，或 JSON 去掉围栏后不可解析）且不是被最大生成长度硬截断的样本，在算 advantage 之前把 completion 的末尾非空白字符置 E（该位 advantage 记 −1.0），其后的尾随空白不置 D、仍是 W；completion 为空、或标注里已有 E 时不施加。该步只作用于 advantage 计算，标注产物里不含这个 E。

6. PPO 裁剪 loss

策略比 ratio = exp(logπ_new − logπ_old) 先在 [0.1, 10] 内截断，再按 policy_ratio_clip_eps=0.2 在 [1−eps, 1+eps] 即 [0.8, 1.2] 内裁剪，损失取 −min(ratio·A, clip(ratio)·A)。聚合是两级平均：先每条序列在自己的动作掩码内平均（分母是该条被训练的 token 数），再对 batch 取算术平均（每条样本等权，不按 token 总数加权）。

作用：区间内梯度正常回传；越界一侧被截平，单步更新幅度受限。

7. 低秩适配（LoRA）

更新范围由一条模块名正则决定：配置项 lora.target_modules 给出这条正则，命中它的线性层各挂一份低秩更新，未命中的权重全部冻结。覆盖语言塔与视觉塔两处——语言塔的注意力投影（q_proj / k_proj / v_proj / o_proj，线性注意力另有 in_proj_qkv / in_proj_z / out_proj）与 MLP 三投影（gate_proj / up_proj / down_proj）；视觉塔的 merger 两个线性层，以及每个 block 的注意力与 MLP 投影。具体落点以正则命中的模块名为准，不逐个层号罗列。

融合 Q/K/V 按整块一份低秩处理：in_proj_qkv 是一个整体模块，只配一份低秩（一对 A: r×hidden、B: out_qkv×r 因子），不拆成 q / k / v 三段各配一份。三点理由：参数更省（一份低秩而不是三份）；低秩因子可跨 Q/K/V 混合，不必按段各学一份；与上游 PEFT 的语义一致（一个线性层一份 adapter，按模块名逐个匹配）。融合块内部的顺序恒为 [q | k | v]。

超参：r=32、alpha=64、dropout=0.05。低秩分支的输出按 alpha/r = 2 缩放后加回原层输出；dropout 作用在低秩分支的输入上，推理时关闭。B 因子零初始化，因此训练起点与原模型逐位相同。

8. 训练指标

指标只用于观察训练是否健康：它不参与第 4 节的决策，也不进入 loss。均值类指标的分母只算终结组（决策不是「重试」的组），重试的中间态只进计数、不进均值。

指标含义看什么
decision_counts每组落在第 4 节哪一档的组数（完美跳过 / 可训练·最优正确 / 可训练·最优不完美 / 重试 / 丢弃）数据难度与丢弃、重试的占比
retry_rate重试组数 ÷ 尝试组数采样效率与重试压力
reward_min、reward_median、reward_mean、reward_max终结组 reward 的最小值、下中位数、均值、最大值整体水位；最大值能否到 1（对应 ②）
reward_nonzero_range_ratereward 组内极差 > 0 的组占终结组的比例还有多少组带偏好信号（极差为 0 时：全部达到或超过满分的组按 ① 跳过；其余按 ⑥ 丢弃，重试次数没用尽时先按 ⑤ 重采）
reward_max_median_gap_mean每组「最大值 − 下中位数」的平均第 ④ 档的可训练幅度有多大
content_mean、base_content_mean内容项归一分的均值 / 剥掉数值叶子后的基础内容分均值内容对了多少；两者差距即数值叶子错的代价
content_all_zero_group_count、content_all_one_group_count组内内容分全为 0 / 全为 1 的组数全 0 组提示内容普遍全错（常因无偏好信号在 ⑥ 丢弃）；全 1 组多为 ① 完美跳过。两者都不等于 ⑥ 的「内容分一致且不满」，后者要求内容分严格介于 0 与 1 之间且组内一致
missing_json_marker_count、unclosed_json_fence_count、invalid_extracted_json_count、likely_truncated_json_count缺 JSON 围栏、围栏未闭合、抽出的 JSON 不可解析、疑似被最大长度截断的 completion 计数格式类失败出在哪一环
tool_call_parse_error_count、tool_call_count_mismatch_count工具调用解析报错、调用条数与目标不符的 completion 计数工具调用形态错的比例

计数单位：attempt_group_count 是尝试过的组数，completion_count = 尝试组数 × N（N 为组大小，见第 4 节），observed_completion_count 是实际收上来、打过分的条数；三者不等即说明有组没凑齐或被拒。

9. 不变式清单

下列判断句应当成立；任一条不成立，即说明实现与本文不一致。

  1. 组完整性：同一提示的 N 条 rollout 必须同批、同版产出，缺一条或跨版混组即不可用于训练。
  2. 奖励与样本一一对齐：每条 completion 恰好一条奖励、一份字符标注、一组 token 级 advantage，且 advantage 长度等于该条生成 token 数。
  3. 算法逻辑严禁改动：标注、奖励、advantage、组决策与裁剪 loss 的算式以本文为准，要改先改本文。
  4. 温度互不覆盖：rollout 采样温度取 training.temperature，默认 1.0（该值按配置生效，不被隐式改写、也不由评测侧改写）；评测温度恒为 0，评测入口不提供覆盖参数。
  5. 标注长度不变式：字符标记长度等于 completion 字符数，token 标记长度等于生成 token 数。
  6. 采样与训练同源：rollout 由当前策略在线采样，旧对数概率即采样时的策略输出，不做多轮陈旧迭代。
  7. 裁剪区间恒定：ratio 的有效区间为 [1−eps, 1+eps]（eps=0.2），不被隐式改写或逐样本缩放。
  8. 值错误不截断：值错误只影响相似度打分，只有结构 / 类型错误才置 E 并在其后标 D；末尾 EOS 是唯一例外——只把末尾非空白字符置 E，其后的尾随空白保持 W。
本文只描述算法本身。
