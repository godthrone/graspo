判据含义与权威读数
判据 ① 能完整跑完训练进程正常退出（exit_code = 0），日志无未捕获异常、未超时、未挂死；算法机制真实生效（不是空转）；产物可被推理或加载；显存与吞吐在承诺范围内。缺失任一即判「不可用」。

2.3 通过的定义

  • 判定单元 = 一行：模型 × 方法 × 模式 × 后端 × 并行维度。native 与 ms-swift 各记各的，不合并、不折算。
  • 通过：每个变体跑一次真实效果训练；该次跑次同时满足两条可用性判据（第 2.1 节）与该算法的算法正确性检查（＝判据 ① 的组成部分：算法机制必须真实生效，不是空转）。
  • 不构成通过的情形：不取多数票；不用短跑或冒烟顶替；不以「跑通即通过」；不以「日志无异常」替代判据。
  • 算法正确性检查（判据 ① 的组成部分）：
    • GRASPO：标注正确性；token 级 advantage 正确；组决策（该训 / 该跳 / retry）；奖励 ↔ 样本对齐；组完整性（G 条齐，不完整必须显式失败）；retry 真实生效；指标诚实（advantages_injected、groups_seen 反映真值）。
    • SFT：prompt 段被正确 mask（loss 只作用 assistant 目标 token）；loss 等于参考交叉熵；packing / padding 不串样本；截断策略按声明执行；分块累积权重等于整批 token 均值；全 -100 批显式拒绝；产物可重载。
    • CPT：全序列 loss（无 prompt mask，或按声明口径）；参数只带预训练项、不带 RL 项；packing / padding 不串样本；纯文本与多模态通路都通；产物可重载。
    • OPD：教师来源二选一互斥；lmbda 固定为 1；gkd_logits_topk 必须具体；数据行为 prompt-only；参数不含 GRPO 奖励接线；蒸馏损失数学（学生 NLL + α·KL）；教师 logits 不参与梯度；师生 token 位置对齐；产物可重载。

2.4 效果基准与「基础设施不应影响效果」

  • 固定量（四者固定后才可比）：训练方法 × 基础模型 × 数据集 × 训练超参。
  • 不变量：基础设施层参数（并行度 / 后端 / 卡数 / 卡分配方式）怎么改，都不应显著影响效果。基础设施层一改效果就显著变化 = 缺陷信号，不是正常波动。
  • 达标门槛 δ：随基准一并冻结（现行口径，见第 2.5 节）；此后 δ 不随跑次漂移。

评测数据集平台方自有 / 不公开。100 行档 = 该档自身训练用的同一份文件（dataset_split: train）⇒ 读数含义是 fit 口径（训练集自评），回答「该档训练是否生效」，不得读作训练分布之外的表现；其余档 = 平台方自有评测集（702 行）。可复核替代锚点（版本标识 / 判据定义 / 样本量 / 评测方法）见第 2.5 节。
训练轮次GRASPO = 8 epoch；SFT = 4 epoch；CPT = 2 epoch；OPD = 2 epoch。多卡不补 epoch。
步数口径步数 = epoch 数 × 每 epoch 推导步数。每 epoch 推导步数：SFT / CPT / OPD = floor(subset_size / cards)；GRASPO × ms-swift = floor(subset_size × G / cards)（G = rollout group size）。表中步数是上限，不是保证；不设人为步数上限（无 max_steps 约束）。
已知偏差（如实披露）：GRASPO × native 的推导式不成立——优化步数由运行期 replay 缓冲区触发次数决定，可训练样本数是运行期结果（取决于 retry 与跳过）⇒ 该组合以实跑累计步数为准。
